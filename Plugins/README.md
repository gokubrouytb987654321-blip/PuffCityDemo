# Plugins locaux Puff City

Les plugins JavaScript places dans ce dossier sont des plugins **locaux au jeu**.

Le Mod Menu fourni est charge par `index.html` et s'ouvre avec **P**.
Il n'est pas publie sur Internet et n'envoie aucune donnee vers un serveur distant.

Pour ajouter un autre plugin au build, ajoute son `<script src="Plugins/NomDuPlugin.js"></script>` dans `index.html`.
