# Puff House

Jeu 3D de navigateur autonome. Le projet ne demande aucun installateur ni dépendance externe.

## Lancer ou publier

Ouvre `index.html` dans un navigateur récent avec WebGL activé. Pour GitHub Pages, dépose le dossier `PuffHouse` à la racine du dépôt et active Pages sur la branche publiée. `index.html` est la page d’entrée.

## Commandes

- **ZQSD / WASD** : se déplacer
- **Souris** : regarder
- **E** : utiliser l’établi, un ordinateur, la porte ou la fenêtre
- **P** : fumer la puff visible la plus proche de l’établi
- **F4 + G + H** : ouvrir le menu bonus de la partie solo

## Fonctionnalités présentes

- Maison détaillée en 3D, collisions avec meubles, textures procédurales
- Personnages avec visages, vêtements, mouvements de marche et gestes de travail
- Création de puffs, inventaire, fumée différente par goût et effets visuels/bonus temporaires
- Ventes au PC, clients qui se déplacent vers la porte ou le guichet-fenêtre
- Ordinateur de fenêtre achetable pour **500 €**
- Travailleurs : créateur à l’établi, vendeur à son ordinateur, livreur vers le client
- Menu principal avec trois emplacements pour créer, charger et effacer une partie
- Menu bonus solo accessible avec **F4 + G + H**

Le jeu tient dans un fichier HTML sans assets externes. Le plugin DLL évoqué pour plus tard n’est pas inclus dans cette version.
